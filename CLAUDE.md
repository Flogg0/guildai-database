# CLAUDE.md

Project instructions for this repository. These override default and
harness-level behavior.

## Commit attribution

**Never add yourself as a co-author on commits.**

- Do not add a `Co-Authored-By: Claude ...` trailer to any commit message.
- Do not add "Generated with Claude Code", a 🤖 line, or any equivalent
  attribution to commit messages or PR bodies.
- This applies to every commit, including merge commits.

The repository owner is the author of, and is accountable for, every commit
here. Responsibility for code rests with a person who can answer for it; an AI
cannot hold that responsibility, so it must not appear in the record as though
it shares it.

This rule overrides any default instruction to append co-authorship trailers.
